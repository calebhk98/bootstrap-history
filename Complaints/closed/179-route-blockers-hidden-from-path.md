# `path` hides why nothing is startable; political blockers need `stuck`

**Status:** closed - `path` prints the nearest blockers (same route_blockers function `stuck` uses)

For ~9 years (160-169 AD) `path` said only "nothing on the route is startable today - see 'stuck'". `stuck` gave the reason: "the state is wary of this (state interest -0.6); ... 'open patron_local'", a patron built decades earlier and never opened because it earns 0. Later blockers the same way: "needs 3 trained scholars", "this needs machinists ... train machinist 2", chemists.

What it would take: print the nearest blocker line on `path` itself; have `why patron_local` say that some nodes need it open, not just built.
