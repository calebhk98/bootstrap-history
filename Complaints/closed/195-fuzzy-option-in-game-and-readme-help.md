# Fuzzy estimates need an in-game option, and the README hides how many commands exist

**Status:** closed - fuzzy estimates are a new-game menu question, an in-game options line (can be turned on, not off), a settings default and stay in the save; README points at help commands

1. `--fuzzy-estimates` (complaint 192) can only be turned on with a command-line flag. Most players never see flags; it should be chosen when starting a game (the new-game menu, next to fog of war), shown in the in-game `options` screen, stored in the save, and have a default in the settings file like other options.
2. A player asked for the README to point at `help commands`: the README lists about ten commands and they did not realise there are dozens. Say plainly near the top of "Playing" that the table is a starting set and `help commands` lists every command (and `help <command>` explains one).
