# Portfolio bottlenecks cover only running work

**Status:** open

`portfolio` groups running projects by blocker kind. It does not group startable-but-blocked work with `start_blockers`, and does not set last year's allocation against this year's forecast.

## What would resolve it

Add a startable-blocked section built from `start_blockers`, and a last-year column from the yearly history. Reported in Complaint 88.
