# lead_metallurgy says Rome already has it, but Rome must build it at great cost

**Status:** open

`why lead_metallurgy`: "This is already done, and done well, wherever there is a developed lead-mining and -working tradition (Rome is the best-documented case)." In a Rome game it is not granted, and costs ~460k (materials 300 t charcoal + 280 t galena) with a 10% failure risk.

What it would take: grant it in Rome's starting set, or have the text say what additional industrial-scale step the node represents.

Found in a new-player playtest (Rome 100 AD, poor_scholar kit, seed 1, played through `play --session`), report: `Complaints/reports/playtest-rome-seed1-new-player.md`.
